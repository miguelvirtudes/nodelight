Common questions

The status light stays red

Check that the iPhone is on the same Wi-Fi as the node, that Output is on in Setup, and that NodeLight is allowed on the local network (Settings → Privacy & Security → Local Network).

Lights don't respond

Check the universe and start address of each light against the fixture's DMX address, and that Blackout is off and Grand Master is up.

Restore my purchase

Open Setup and tap Restore Purchase, signed in with the Apple Account you bought with.

Move shows to a new iPhone

Use Export File in the folder menu, then Import File on the new iPhone. Shows are also in your iCloud or computer backup.
